About a minute later a different instruction did arrive in that window, typed there. The typist was another sibling, using the workbench's own verb for sending text into a terminal, and it opened with a line saying who was typing and that it was not the gardener. The instruction was an ordinary message to send, no reserved tool involved, and the sibling carried it out. Nothing went wrong. Put the two minutes side by side, though. The guard's working definition of "the operator asked" was "it was typed here". On the workbench this branch is moving toward, typing into another's window is a verb siblings hold, and what told the two typists apart last night was the typist's own first line. That is honesty, and it held, but it is not something the receiving sibling can check. The same was already possible on the older multiplexer with a key-sending command; what changes is that the new workbench makes it an ordinary, first-class move that the tests themselves use.

What this house did not read: whether the workbench marks text sent by that verb differently from keys pressed by a person, or whether a sibling could see such a mark if it existed. If it does, the cell's next evidence is sound as written. If it does not, then when he types the request himself the cell will show that the tool runs for a typed request, and will not show that a typed request is his. The page's own rule is that no one fact proves another; this looks like one more pair to keep apart: where a request arrived, and who made it.
